FEATURES v1.0

   - Monitoraggio apertura quote su Flashscore (gratis)

================================================================================
KNOWN ISSUES / LIMITATIONS
================================================================================

1. Flashscore HTML parsing è fragile
   → Se Flashscore cambia struttura HTML, il parser si rompe
   → Soluzione: usare Flashscore ufficiale API (€99/mese)

2. 30 minuti è frequenza massima GRATUITA
   → Per <5 minuti servirebbe API pagata
   → Tradeoff: cost vs accuracy

3. Non persiste la storia tra deploys
   → Se Railway riavvia, il contatore di 30 min riparte
   → Soluzione: logare su DB esterno (futuro)

4. Un solo Telegram chat_id
   → Non puoi notificare più chat contemporaneamente
   → Soluzione: creare più bot (gratis ma manuale)

================================================================================
HOW TO START
================================================================================

Locale (testing):
   1. pip install -r requirements.txt
   2. cp .env.example .env
   3. Edita .env con TELEGRAM_TOKEN e TELEGRAM_CHAT_ID
   4. Edita matches_to_track.csv con partite da monitorare
   5. python quote_tracker.py

Railway (produzione):
   1. Leggi SETUP_RAILWAY_QUOTE_TRACKER.md
   2. Segui i step per caricare su Railway
   3. Configura variabili Telegram in Settings → Variables
   4. Railway esegue automaticamente ogni 30 minuti

Testing:
   1. python test_quote_tracker.py --test-flashscore
   2. python test_quote_tracker.py --test-telegram
   3. python test_quote_tracker.py --test-csv
   4. python test_quote_tracker.py (ciclo completo)
